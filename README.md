# birthday
PROJECT: ASHARI — THE MIDNIGHT BIRTHDAY
======================================

Cara menjalankan:
  Buka index.html langsung di browser (Chrome / Safari / Firefox),
  atau jalankan local server:
      python3 -m http.server 8000
  lalu buka http://localhost:8000

File:
  index.html   — struktur 5 landing page
  style.css    — design system Midnight Blue Luxury
  script.js    — seluruh interaksi, audio (Web Audio API), animasi

Catatan:
  - Audio baru aktif setelah interaksi pertama (aturan autoplay browser).
  - Tombol speaker kanan atas untuk mute/unmute.
  - Font utama Cinzel (Google Fonts); fallback otomatis ke serif jika offline.
